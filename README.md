# 🤖 دستیار هوشمند لیارا (Liara AI Assistant)

## 📖 معرفی
این پروژه یک دستیار هوشمند برای مدیریت زیرساخت‌های ابری در پلتفرم لیارا است. این ابزار به کاربران (حتی بدون دانش فنی) اجازه می‌دهد تا اپلیکیشن‌های خود را دیپلوی کنند، وضعیت منابع (CPU/RAM) را پایش کنند و در صورت بروز خطا (مثل HTTP 500)، به صورت هوشمند عیب‌یابی کنند.

## 🏗 معماری
- **Frontend:** Next.js (App Router) + Tailwind CSS (طراحی مدرن و ریسپانسیو)
- **AI Engine:** مدل‌های زبانی از طریق API (BoxAPI)
- **Backend Integration:** استفاده از پروتکل MCP (Model Context Protocol) برای اتصال امن به لیارا.
- **Human-in-the-Loop:** سیستم تأیید دو مرحله‌ای برای عملیات حساس (Restart/Delete).

## 🔌 نحوه اتصال به APIهای لیارا
برای اتصال، از پکیج رسمی `liara-mcp` استفاده شده است. توکن دسترسی از طریق متغیر محیطی `LIARA_API_TOKEN` به سرور ارسال می‌شود. 

**ابزارهای استفاده شده:**
- `liara_list_apps`: دریافت لیست اپلیکیشن‌ها
- `liara_get_metrics`: دریافت متریک‌های CPU و RAM
- `liara_restart_app`: ری‌استارت اپلیکیشن (با تأیید کاربر)
- `liara_get_logs`: دریافت لاگ‌ها برای عیب‌یابی

## ⚠️ محدودیت‌های راهکار
- دسترسی به API تنظیم دامنه (ایرنیک) در این نسخه پیاده‌سازی نشده است.
- به دلیل محدودیت‌های API لیارا، امکان ایجاد برخی منابع خاص به صورت کامل وجود ندارد و سیستم در این موارد به کاربر اطلاع می‌دهد.

## 💡 نحوه تعامل کاربر
۱. کاربر اپلیکیشن مورد نظر را از سایدبار انتخاب می‌کند.
۲. دستور خود را به زبان طبیعی (مثلاً "سایتم کند شده چک کن چرا") می‌نویسد.
۳. دستیار با استفاده از ابزارها، لاگ‌ها و منابع را بررسی می‌کند.
۴. در صورت نیاز به تغییر (مثل ری‌استارت)، یک کارت تأیید (Confirmation Card) به کاربر نمایش داده می‌شود.
۵. پس از تأیید، عملیات انجام شده و نتیجه گزارش می‌شود.
